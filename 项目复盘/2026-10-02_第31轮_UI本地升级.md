# 第31轮：晨报卡 UI 本地升级

本轮把原生卡片的首页、授权、列表、阅读和主编统一为“破晓编辑部”风格。主要改善是中文字体一致、授权操作清楚、长标题可读、主编不覆盖正文，以及小屏底栏和输入区可用。

真实宿主经过 Windows 本地构建，按320/412/768/1280px检查，使用独立状态和本地新闻/语音布局 fixture。修复过程中发现并解决阅读重建的嵌套字段错误、对话记录隐藏冲突和持续动画帧问题，测试现在检查日志。

详细改动、证据、命令与未验证能力见 [UI验收报告](../docs/UI验收报告.md)。本轮只准备本地版本，等待用户醒后决定，不推送、合并远端或发布。已有角色、草案与参考素材保持原样。
