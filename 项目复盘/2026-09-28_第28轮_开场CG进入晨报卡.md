# 第 28 轮：开场 CG 进入晨报卡（宿主内实测）

日期：2026-09-28
作品：morning-brief（晨报卡）0.1.0
本轮目标：把已验证的开场 CG「Dawn / 破晓」从独立探针搬进真实晨报卡，并且不影响原有三视角编辑部与视觉主编流程。

## 一、做了什么

在 `my-entry\morning-brief\bundle\main.splash` 的根 `HostedView.full`（`flow: Overlay`）里，作为最后一个子控件插入 `cg := View{width: Fill height: Fill show_bg: true ...}`，用 SDF pixel shader 直接画整个开场动画；文字用三层 Label（`cg_eye` / `cg_ttl` / `cg_rul`）叠在 shader 之上。

时间轴（秒，脚本内 `cgT = self.draw_pass.time`）：
- 0.55–1.70 排版网格淡入（44px 网格，青色网格混一点晨光色）
- 0.25–2.60 4 颗数据粒子螺旋向内汇聚（半径 380→38）
- 1.70–2.90 破晓光带自下而上掠过（近白核心 + 暖金外晕）
- 0.20–3.35 品牌洋红 `#xe0245e` 扫描线缓慢下移
- 2.90–3.08 收尾白闪（峰值即切出）
- 3.12 `start_timeout` 触发 `cg_off()`：清空三个 Label 文本并 `ui.cg.set_visible(false)`

## 二、关键坑（都踩过并已修）

1. **`HostedView` 只渲染 `full` 与 `tile` 两个槽位。**
   第一次把 `cg` 放在 `HostedView` 里与 `full`/`tile` 平级，编译通过、运行不报错，但 CG 完全不显示——被静默忽略。
   修法：放进 `full` 的 `Overlay` 内部、作为最后一个子节点（Overlay 是后绘制在上）。

2. **连续多个不透明全屏 `sdf.fill()` 会互相覆盖，只有最后一次生效。**
   独立探针 v1 里网格/粒子/光带全被后来的全屏填充抹掉，截图只剩底色+文字。
   修法：每一层 `mix` 进一个本地 `var cgCol`，最后只 `return vec4(...)` 一次。

3. **写着色器变量名必须带前缀。**
   短名 `cx/cy/r/a` 会与内置符号冲突，导致连锁编译失败、`draw_bg` 整块消失。本轮统一用 `cg*` 前缀。

4. **`set_visible(false)` 只隐藏 shader 背景，不隐藏兄弟 Label 的文本。**
   首次淡出后，`晨报卡 / AI EDITION / — 今日头版 —` 会继续压在新界面上。
   修法：`cg_off()` 里先逐个 `set_text("")`，再 `set_visible(false)`。

5. **白闪峰值与切出时刻必须对齐。**
   白闪早已结束、`cgOut` 才降到 0，会看到"暗底文字压在界面之上"的一帧。调整为闪光峰值 3.08s、切出 3.12s，视觉上是"一道白光闪过 → 就是界面"，交接干净。
