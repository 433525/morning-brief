# 第二轮：破晓编辑部

2026-10-02，用户新增Awwwards、Webby Awards、FWA标准并授权约10:02–18:02本地实施。首轮基线2ae6c9e可回退，仍不发布。

## 本轮判断

当前版可读和可用，但刊头、设置和来源三块大圆角卡同等强调；320px主操作偏下；三编辑与企鹅女孩还没有成为贯穿阅读路径的结构。独立只读设计复核给出同样结论。

保留墨蓝、冷白、莓红、琥珀和现有字体，把大胆选择集中在“破晓编辑部”的刊头与版面节奏。复用企鹅女孩素材，让角色出现在主编入口。控件尺寸和真实状态优先于装饰。

## 实施目标

1. 刊头约110–128px，日期/品牌/栏目线层级清楚，使用静态晨光标记；首页连续任务区，减少重复说明与大容器堆叠，让320px主操作更快出现。
2. 按现有顺序区分“本期首条”与其余新闻，保留来源、时间、已有理由和真实编辑意见。其余条目降低容器权重。阅读只显示一次完整标题；不制造头条身份、评分或阅读时长。
3. 角色锚定主编入口和面板，依据phase/ag_busy/vc_listen显示状态；授权可直接回到偏好设置。动效只用于短反馈，减少动态时静态。

## 第一批实施结果

- 320x568首屏主操作断言：首轮FAIL（按钮还没进入可见控件树），新版PASS；四尺寸基础流程通过。
- 刊头使用静态原生晨光线，不新增图片/字体、不注册持续动画；首页从“横幅＋两块大卡片”改为连续任务区。角色锚定到dock，原PNG保持完整。
- 新闻首条沿用真实排序，标为“本期首条”；其余条目降低背景权重并用分隔线。入选理由由真实已有数据提供，空值不补；阅读重复短标题隐藏。
- “待批准”与修改偏好入口来自真实phase/复用restart；三编辑行区分等待、返回意见和失败。
- 320/412长标题、正文滚动后换条、模拟双语音/非空消息；768/1280列表阅读、四尺寸首屏；开场有限计时与空闲状态已验证。新版仍通过未签名Hub包检查。

## 只读复核后的修正

- 三编辑汇总原用`panel.len()`称“已交回意见”，包含失败结果，和新角色行矛盾。改为“已返回项结果”，角色行继续显示真实成功、失败和等待；不改选稿逻辑。
- judging副本的说明原只存于未显示的`panel_note`。现在副本覆盖`judge_line`为“本地 UI 模拟 · 未调用模型”，截图与脚本均验证可见，实际产品不添加模拟标签。
- 320首页重截，长占位文案改为“例如：AI 和芯片的新进展”；来源与时间允许两行并统一中文。带缩略图行有独立`14-thumbnail-row.png`证据。
- 缩略图fixture需将`{{assets}}`放在脚本字面量中，宿主不会展开JSON里的同名字符串。测试副本已修正，相关最新日志无渲染/回调错误；这不是生产来源逻辑改动。
- 新增授权页“修改偏好”的实际点击验证，检查关注主题与条数保留后可再进入计划，不批准取数。
